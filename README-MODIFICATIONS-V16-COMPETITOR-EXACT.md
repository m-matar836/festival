# V16 – مبيعات المنافس مطابقة لقسم المبيعات

- قسم مبيعات المنافس يظهر فقط عند نوع الحدث `ترويج مولات`.
- واجهة مبيعات المنافس أصبحت بنفس بنية قسم المبيعات: باركود USB، كاميرا، زر مسح، جدول مادة/سعر/كمية/مجموع/إجراء، وإجمالي.
- المواد تُقرأ من `ProductsOfCompetitor` مع تجاهل المواد الملغاة.
- تم تغيير إصدار الكاش المحلي إلى V16 لمنع بقاء قائمة المواد القديمة.
- تم الحفاظ على التخزين في `salesOfCompetitor` بالأعمدة: reportId, product, price, quantity.
- تعديل التقرير يعيد تحميل مبيعات المنافس من الشيت.

# V20 – سجل التقارير حسب المستخدم + إخفاء جدول المبيعات

اعتمدت هذه النسخة على الموقع السابق كما هو، وأضافت فقط:

1. حفظ مالك التقرير عند الإنشاء عبر `createdById` و`createdByName`.
2. عند تعديل تقرير، يبقى المالك الأصلي للتقرير محفوظاً ولا ينتقل إلى المستخدم الذي عدّله.
3. سجل التعديلات للمستخدم العادي يعرض تقاريره التي أنشأها هو فقط، بينما admin يرى جميع التقارير.
4. يتم إنشاء عمودي `createdById` و`createdByName` في ورقة `Reports` تلقائياً إذا لم يكونا موجودين.
5. عند اختيار نوع الحدث `ترويج مباشر` يختفي جدول المبيعات بالكامل، ويتم تفريغ بياناته حتى لا تُحفظ مبيعات بالخطأ.
6. عند اختيار أي نوع حدث آخر يعود جدول المبيعات للظهور بشكل طبيعي.

لم يتم تغيير منطق باقي أقسام الموقع.

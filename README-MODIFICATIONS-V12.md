# التعديلات المضافة

اعتمدت هذه النسخة على promotionReport-main(8).zip فقط.

1. أزرار إضافة المحافظة والمنطقة واسم المحل تبقى بجانب الحقل داخل input-group.
2. إضافة حقل `phoneNumber` لرقم هاتف صاحب المحل بجانب الأشخاص المتواجدين بالنقطة.
3. `phoneNumber` يصبح مطلوباً فقط عندما يكون نوع الحدث `ترويج وبيع غير مباشر`.
4. عند الحفظ، يتم إنشاء عمود `phoneNumber` في Reports تلقائياً إذا لم يكن موجوداً، ثم حفظ الرقم فيه.
5. تعديل سعر المادة من جدول المبيعات يرسل السعر مباشرة إلى Products ثم يحدّث الكاش المحلي تلقائياً.
6. إضافة endpoint في Code.gs باسم `updateProductPrice` لتحديث السعر في Products.
7. منع تكرار مسح USB للباركود الناتج عن إرسال الجهاز لحدث input ثم Enter خلال أقل من 800ms؛ وبالتالي الكمية تصبح 1 ثم 2 ثم 3 بدلاً من 1 ثم 2 ثم 4.

- تم اعتماد هذه النسخة من الملف المرفوع كما هي مع تحسينات أداء محافظة.
- `getInitialData` يقرأ فقط الأوراق المطلوبة بدل المرور على كل أوراق الملف.
- تم منع القراءة المكررة لـ `ProductsOfCompetitor` أثناء بناء البيانات الأولية.
- تم تحسين التحقق من وجود المستخدمين قبل القراءة لتجنب أخطاء الصفوف الفارغة.
- تم رفع نسخة الكاش المحلية ونسخة Service Worker لإجبار المتصفح على استخدام الأصول الجديدة.
